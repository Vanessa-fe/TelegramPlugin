## 🐛 Problèmes résolus

### 1. Erreur "Cannot read properties of undefined (reading 'call')"
**Cause** : Cache Next.js corrompu
**Solution** : `rm -rf .next && pnpm dev`

### 2. Images cassées dans le blog
**Cause** : Fichier `/public/og-image.png` manquant
**Solution** : Copie temporaire du logo, puis remplacement par la vraie image OG fournie par l'utilisateur

### 3. Erreurs TypeScript dans les schemas
**Cause** : Types schema-dts stricts pour Review et LocalBusiness
**Solution** :
- Review : Simplification avec `itemName: string` au lieu de `itemReviewed` complexe
- LocalBusiness : Suppression de `openingHours` (type incompatible)

### 4. Menu Ressources qui disparaît au hover
**Cause** : `onMouseLeave` ferme immédiatement le menu
**Solution** : Ajout d'un timeout de 200ms + handlers sur le dropdown lui-même
**Note** : Problème de cache navigateur côté utilisateur à résoudre avec hard refresh
