## 🎓 Apprentissages techniques

### 1. Traduction dynamique reading-time

**Problème** : Bibliothèque retourne texte en anglais
**Solution** : Calcul manuel + détection locale
```typescript
const stats = readingTime(content);
const minutes = Math.ceil(stats.minutes);
const formattedReadingTime = locale === 'fr'
  ? `${minutes} min de lecture`
  : `${minutes} min read`;
```

### 2. Gestion cache Next.js

**Symptôme** : Erreur "Cannot read properties of undefined"
**Diagnostic** : Cache `.next` corrompu + serveurs multiples
**Fix** : `rm -rf .next && pkill -f "next dev" && pnpm dev`

### 3. Commits avec HEREDOC

**Best practice** pour messages multi-lignes :
```bash
git commit -m "$(cat <<'EOF'
Message sur plusieurs lignes
avec formatage préservé
EOF
)"
```
